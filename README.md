## **Адаптивная верстка** — это подход к созданию веб-страниц, при котором дизайн и контент автоматически подстраиваются под размер экрана устройства (компьютер,планшет, смартфон).
## **Grid** — двумерная система компоновки для создания сложных сеток.
## **Описание:**
В данной лабораторной работе мы поработали с сеткой Grid, попркатиковались посоздавать шапку, основное и подвал. Для чего мы это делали? Чтобы научиться создавать красивый и немало важно информативный сайт, в котором всё что нужно пользователю будет подсвеченно и аккуратно выделенно.
Так же мы закрепляем знания CSS и добавляем новые, например сегодня я узнал, как сделать так, чтобы при наведение курсора на выделенную область, она аккуратно открылась, при этом не резко, а с устоновленным таймер на открывание. **Фрагмент кода:**
```CSS
.gallery-item {
    background-color: #2196f3;
    color: white;
    padding: 60px;
    text-align: center;
    border-radius: 5px;
    transition: transform 0.3s;
}

.gallery-item:hover {
    transform: scale(1.05);
}
```
Так же хочу в своем описании хочу привести таблицу - **Сравнение Flexbox и CSS Grid**.
| **Критерий** | **Flexbox** | **CSS Grid** |
|:-------|:---------:|:---------:|
| **Тип компоновки** | Одномерная | Двумерная |
| **Управление** | Строка или столбец | Строки и столбцы |
| **Основное назначение** | ыравнивание элементов | Построение макетов |
| **Подходит для** | Компонентов | Страниц и сеток |

**Вывод:** Flexbox лучше подходит для **линейных структур**, Grid — для **табличных и сложных**.
